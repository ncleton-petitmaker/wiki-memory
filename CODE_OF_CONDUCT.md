# Code of Conduct

## Our standard

Wiki Memory welcomes contributors of every background and experience level. Participate with empathy, technical honesty, and respect for other people's time, identity, privacy, and data.

Expected behavior includes giving specific feedback, separating criticism of ideas from criticism of people, acknowledging uncertainty, respecting consent, and making room for newcomers.

Unacceptable behavior includes harassment, discrimination, threats, sexualized conduct, doxxing, sharing private data without permission, deliberate disruption, or evading moderation decisions.

## Enforcement

Report conduct concerns privately through the maintainers' GitHub contact surface. Do not use a public issue when doing so could expose a target or reporter. Maintainers may edit or remove content, close discussions, restrict participation, or ban accounts when necessary to protect the community.

Enforcement decisions should be proportional and free from retaliation. Maintainers with a conflict of interest should step away when another maintainer is available.

## Scope

This code applies in repository spaces and when someone represents Wiki Memory in public community spaces.
